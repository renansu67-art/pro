# XoPhone AI — Android starter

This is the first native Android starter project for the Infinix X6525 / Android 13 target.

## Included
- Dark dashboard
- Overlay permission hand-off
- Start/stop floating AI service
- Draggable purple AI bubble
- Small floating information panel
- Foreground notification while the bubble is active

## Build
1. Open this folder in Android Studio.
2. Allow Gradle sync.
3. Build > Build APK(s).
4. Install the debug APK on your Android phone.
5. Open XoPhone AI, enable the floating/“display over other apps” permission, then tap Start Floating AI.

## Notes
- Uses package ID `com.xophoneai`.
- Target SDK 33, minimum SDK 26.
- This is a starter, not a finished repair tool or game-playing bot.
- Diagnostic checks and AI responses are not connected yet.
- Android may show a notification while the floating service is running.
